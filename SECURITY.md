# Security

## Reporting a problem

Please don't report security problems in a public issue or discussion. Use [Report a vulnerability](https://github.com/wildorigins/wildos/security/advisories/new) under the Security tab instead, so it stays private until a fix is out.

Tell us what you found, how to reproduce it, and which Wild OS version you're on (Settings, System, About). If you have an idea of how bad it is or how to fix it, include that too.

You'll get a reply, and you'll be told when it's fixed. If you'd like credit in the release notes, say how you want to be named.

## What's covered

The latest Wild OS release, which is currently Alpha 1. That includes the installer, the Wild OS packages, Windows mode and the update channel at deb.wildos.io.

Wild OS installs Debian, KDE and its security hardening packages unmodified from their own repositories. If the problem is in one of those, report it to that project as well. We'll still want to hear about it, because it may affect how Wild OS sets things up.

## What isn't

Windows itself, running inside Windows mode, is Microsoft's. Problems with how Wild OS boxes Windows in are ours.
