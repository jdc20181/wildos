# Which icon each LibreOffice command or image gets in the Wild OS theme.
#
#   target   icon   [tone]
#
# A target is a UNO command (Bold, for .uno:Bold) or a LibreOffice image path
# with the size it is drawn at (svx/res/doc_modified_no.png@16). An icon is a
# file in svg/ (drawn on the design boards or by us) or lucide/ (adapted from
# Lucide). Tones: fg (default, the text colour), accent for the actions the
# boards draw in blue, muted for the sidebar strip and status bar, and red,
# yellow, green where the colour carries meaning.
